Lightbeam is an AI data security and guardrails platform that discovers and classifies sensitive data across cloud, SaaS and on-premises systems, ties that data to identity and access context through its Data Identity Graph, and enforces guardrails on how users, applications, copilots and AI agents reach it. Capabilities span AI security and shadow-AI detection, data security posture management (DSPM), data classification, risk scoring, automated remediation, access governance, privacy operations, data retention, breach and ransomware blast-radius reduction, and user entity behavior analytics. Founded by former Nutanix leaders and backed by Vertex Ventures US, 8VC, Village Global, Monta Vista Capital and Dropbox. Lightbeam sells to the enterprise and publishes no public API - its documentation portal is authentication-gated.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Lightbeam: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
